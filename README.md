## 一句话简介

你是灰烬港的除祓师。某个暴雨夜，你在巷子里捡到了一只被同族丢弃、饿到只剩一口气的魅魔——**他美得惊心动魄，以欲望为食，却是一个「不举」的魅魔**。

他不是天生的残次品。他的心核熄灭了。

而唤醒它的方法，藏在你的每一个选择里。

## 游戏特性

- **9 个结局**：3 个长文本结局（各 3000 字+）+ 6 个短文本结局（各 800 字+），全部有完整可玩内容
- **分支叙事**：序章起每一章都有影响命运的选择，数值系统（心核 / 信任 / 侵蚀 / 牵绊）驱动分线
- **R18 内容**：文学化露骨 + 擦边 + 直白描写混合，入场需通过 18+ 年龄确认
- **酒馆美化风 UI**：暗色绒面 × 古董金描边 × 蕾丝玫瑰纹样 × 毛玻璃面板
- **全立绘演出**：男主角 6 种表情立绘（图生图保证人物全程一致），配角立绘 + 8 张手绘风场景背景，随剧情自动切换
- **系统功能**：存档 / 读档 / 自动存档 / 历史回看 / 结局收集图鉴 / 主角改名 / 打字机效果


## 内容警告

本作为虚构成人向恋爱游戏，包含：明确性描写、心理创伤叙事、宗教审判与轻度暴力描写、支配型关系描写。所有角色均为成年人。未成年人请勿访问。
